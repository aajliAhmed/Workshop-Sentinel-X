# Workshop-Sentinel-X
📋 Présentation

**SENTINEL-X** est un système de surveillance physique autonome conçu pour
sécuriser des infrastructures industrielles isolées et exposées à plusieurs
types de menaces :

- 🔴 Intrusions physiques
- 🟠 Risques environnementaux
- 🟡 Surchauffes thermiques
- 🔵 Fuites de gaz / fumées
- 🟣 Déstabilisation réseau et cyberattaques

Le système repose sur un **ESP8266**, connecté à
différents capteurs environnementaux et à un **PC Serveur Local** chargé de
centraliser les données, exécuter les traitements IA et fournir l'interface
de supervision.


## Security & MQTT Attack Simulation
